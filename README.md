## About

**Dineery** is a simple, image-led restaurant website created as a college project. Visitors can explore the restaurant home page and browse meals, drinks, and desserts through a warm, responsive interface.

The site is built with plain HTML, CSS, and JavaScript—there is no framework, build step, or backend.

## Features

- **Restaurant home page** with venue photos and introductory descriptions.
- **Food and drink menus** organized into dedicated pages.
- **Menu categories:** breakfast, lunch, and dinner; hot and cold drinks.
- **Dish cards** with photos, names, and displayed prices.
- **Interactive navigation** with a compact menu on smaller screens.
- **Responsive styling** for different screen sizes.

## Getting started

### Requirements

- A modern web browser
- A local web server (recommended, for example, the **Live Server** extension in Visual Studio Code)

### Run locally

1. Clone or download this repository.
2. Open the project folder in your editor.
3. Start a local server from the project root.
4. Open the server's URL in your browser and choose `Index.html`.

> **Tip:** Serving the project from its root folder helps the site's `/Assets/...` image paths resolve correctly.
